## 가설 · 결정 (v1 과 같은 기준)

- **H1** 요청당 (K − C) 토큰 평균의 단측 95% 부트스트랩 상한 < 0
- **H2** 요청당 (K − C) ms 평균의 단측 95% 상한 < 0
- **H3** K 의 앞단 오답률 ≤ 5%
- **결정:** H1 · H3 이 서면 앱 기본을 `WORLDPLAN_FRONT=clock` 으로 바꾼다. 아니면 `off` 그대로
- 부(副): clock 부류 정답 수 — C 와 K 를 나란히(이번에는 C 도 지금 시각을 안다)

## 미리 적는 기대 — 과장하지 않으려고

K 가 아끼는 것은 **시각 질문의 몫뿐**이다. v1 섞임에서 그 몫은 −21% 였다. 실제 사용에서 시각 질문이 드물면
절감도 그만큼 작다. 부류별 수에서 기대 절감 = p(clock) × (clock 의 C 평균 − K 평균) 으로 다시 셀 수 있다.
