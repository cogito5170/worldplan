## 우리가 다르다고 **주장하는** 점 (위 조각들에서 못 본 것 -- '없다' 가 아니라 '못 봤다')

1. **여러 일정을 한 번에**: 선후(after + gap) · 하루 상한 · buffer · 체류지 이동(stays) 을 함께 푼다
2. **생성자와 심판 분리**: 생성자가 낸 계획, 혹은 LLM·사람이 낸 계획을 **다른 계산 경로의 결정적 심판**이
   다시 재고, 기본은 REJECT
3. **최적성 주장 제한**: 탐색이 끝까지 돈 경우에만 proven_optimal. 한도에 걸리면 그렇게 말한다
4. **판정 원장**: 해시 사슬. 일정 내용 없이 입력 해시와 판정만
